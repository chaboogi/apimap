# 어디까지 가나요?

출발지와 도착지를 검색하고 자동차 도로 거리를 확인하는 정적 웹앱입니다.

## 실행

Node.js 18 이상이 필요합니다. 별도의 패키지 설치나 환경변수 설정 없이 실행할 수 있습니다.
Redis, 데이터베이스, API 키도 필요하지 않습니다.

```bash
npm run build
```

생성된 `dist/` 폴더의 정적 파일을 배포하면 됩니다. GitHub에 저장소를 만든 뒤 Vercel에서 저장소를 Import하면 `vercel.json` 설정으로 빌드됩니다.

## 데이터 제공처

- 장소 검색: [Nominatim](https://nominatim.org/)
- 자동차 경로 거리: [OSRM](https://project-osrm.org/) 공개 데모 서버
- 지도 링크 및 지도 데이터: [OpenStreetMap](https://www.openstreetmap.org/copyright)

장소 검색 결과를 선택해야 경로를 계산할 수 있습니다. 검색 요청은 입력 후 대기 시간을 두고 보내며 브라우저에 검색 결과를 캐시합니다. 공개 데모 서버는 사용량 정책에 따라 요청이 제한되거나 일시적으로 중단될 수 있으며, 상용 서비스나 많은 사용자가 이용하는 서비스에는 자체 호스팅 또는 별도 제공처를 권장합니다. 이 앱은 자동차 경로 거리를 표시하며, 실제 주행 시간이나 교통 상황은 제공하지 않습니다.
